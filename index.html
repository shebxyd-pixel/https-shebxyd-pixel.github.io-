02. Algunos de mis proyectos

Proyecto Destacado

Proyecto_Kofu

Una Inteligencia Artificial local diseñada para crear archivos directamente en tu computadora sin necesidad de conectarse a internet. Este proyecto utiliza el motor de Ollama (gemma4) y está enfocado al ámbito profesional, actualmente en fase de producción y desarrollo beta.
Python Ollama Gemma4 IA Local

Bifurcación de Kofu

Proyecto_Hino

Un Agente de IA especializado en generar documentos y es la bifurcación de Kofu con menos módulos siendo un Agente Experimental. Su principal característica es que no cuenta con módulos de filtrado ni de seguridad y la forma en la que sirve los puertos es más optimizada para correr en computadoras menos potentes y dejar espacio para los cerebros.
Python Office Ollama

IA Portátil

Proyecto_Nara

Un Agente de Inteligencia Artificial escrito en Kotlin que usa la arquitectura llama.cpp para correr modelos de forma local usando archivos .GGUF sin necesidad de servidores ni suscripciones. Tiene habilidades de hacer llamadas a funciones del sistema usando etiquetas Regex.
Kotlin Java Llama.cpp

Juego Independiente

55shG4M

Un juego desarrollado íntegramente en C++. El proyecto está en constante evolución y su código fuente es completamente abierto para estudio. Es un excelente ejemplo de manejo de memoria y lógica de videojuegos desde cero sin motores gráficos pesados.
C++ Game Development Open Source

IA Móvil

Proyecto_Nara

Una IA local que corre de forma 100% offline usando la arquitectura de llama.cpp con capacidades de ejecución y con habilidades de control de dispositivos usando corrutinas y etiquetas regex.
llama.cpp GGUF Kotlin

Suite Automatizada de edición

Proyecto_Kroma

Una suite con herramientas de edición de fotos y videos impulsada por FFmpeg y modelos vision para elegir clips y fotos. Está conformada por 3 Agentes: Riku, Miro y Kroma.
Python ffmpeg Ollama

Agente de Pentesting

Proyecto_Kiru

Un prototipo de Agente optimizado para pruebas de pentesting usando un cerebro de 4b sin censura conectado a bases de datos públicas de vulnerabilidades como 'PayloadAllThings' y con una interfaz de sandbox con acceso a la terminal usando un script intermediario de Python.
Ollama Python Bash
